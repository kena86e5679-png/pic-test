# SPATIAL PERCEPTION AR：1m 陣列定位、軌跡範圍虛線勾勒與實心建築系統 (v5)

結合登入前目標玩家照片特徵建檔、1m×1m 空間格狀陣列標記、後台軌跡虛線範圍勾勒與實心不透明建築生成的混合實境系統。

---

## v5 四大更新重點

1. **一公尺格狀陣列標記系統 (`GRID_STEP = 1.0m`)**：
   - 空間中的標記物改為 **每隔 1.0 公尺** 規則排列的高密度矩陣陣列（涵蓋 25×25 共 625 個 1m 座標錨點：`A-1`, `A-2` ... `Y-25`）。
   - 手機端與 Dashboard 均做視錐與距離裁剪最佳化，靠近至 **1.65 公尺內** 自動激活並回傳伺服器。
2. **後台空間軌跡紀錄 ＋ 虛線勾勒探索範圍 (`dashboard.html`)**：
   - 玩家的移動軌跡座標點全數靜默儲存在後台（`traces`），不在地圖上畫出雜亂的歷史折線。
   - 監控端透過 **Monotone Chain 凸包與外擴緩衝演算法（Expanded Convex Hull）**，即時在後台軌跡數據的外圍用**青色虛線（`setLineDash([8, 6])`）**將玩家探索過的空間範圍完整勾勒出來。
3. **實心不透明虛擬建築生成 (`Solid Opaque Structures`)**：
   - 手機端 AR 中的虛擬建築由原本的透明線框改為**實心不透明混凝土量體**：透過 3D 六面體面片投影、近平面裁切（Near-Plane Clipping）與**畫家演算法（Painter's Algorithm 由遠至近排序）**繪製不透明面，能直接遮蔽後方的標記物與背景；Dashboard 地圖上也同步以實心不透明色塊呈現。
4. **Log in 前強制拍攝對手玩家照片（敵人視覺特徵建檔）**：
   - 在進入系統（Log in）前，使用者必須先開啟預覽鏡頭，對準除了自己以外的另一位連機玩家拍攝照片。
   - 系統會即時擷取對手玩家的**上半身/下半身衣著主色調與 24-bin 色彩直方圖特徵（`targetProfile`）**，完成鎖定後才解鎖「登入空間系統」按鈕，並在遊戲中結合 COCO-SSD 人體偵測與色彩特徵相似度比對來鎖定敵人（顯示特徵吻合度百分比、白色虛線框與淡紅色濾鏡）。

## 新增：AI 空間層次判讀與線上模型訓練工作台 (`trainer.html`)

可直接於 GitHub Pages (`https://你的帳號.github.io/你的專案/trainer.html`) 開啟：
1. **上傳單張空間照片**：自動透過 **COCO-SSD + 透視地牆交界線與垂直峰值演算法** 加上 **TensorFlow.js 多層感知器神經網路 (`Spatial MLP`)** 判讀空間。
2. **視覺化修正與框選**：可在照片上直接按住滑鼠拖曳，框選被漏判的「陽角、陰角、門扇開口、封閉牆面死路、阻擋桌椅或半高掩體」，並設定其屬於「前景 (0~2m)、中景 (2~5m) 或後景 (5m+)」以及「實體優先之空間處置規則」。
3. **即時回饋訓練 (`model.fit`)**：按下「確認修正並回饋訓練模型」，瀏覽器會立即執行倒傳遞訓練更新神經網路權重（自動保存於 `localStorage://ar-spatial-mlp-v1`），並支援將累積的訓練數據庫匯出為 `spatial_dataset.json`。
